# Helix Frontend

React and Vite frontend for Helix, a real-time chat app with authentication, online presence, text messaging, and image sharing.

## Scripts

- `npm run dev` starts the local Vite dev server.
- `npm run build` creates the production build.
- `npm run lint` runs ESLint.

## UI

The interface uses a dark Helix theme with Inter, glass panels, real conversation states, and no placeholder actions.
